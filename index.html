GitHub setup

Upload index.html and projects.json together to a public GitHub repository and enable GitHub Pages. Enter the repository owner, name, branch and the path to projects.json. Settings can also be set in DEFAULT_GITHUB in the HTML before publishing.

For editing, create a fine-grained GitHub personal access token restricted to this repository with Contents: Read and write permission. Sign in with that token. It is kept only in this browser tab, and is cleared when you sign out or close the tab. Never put a token in this HTML or repository.

Anyone can read the JSON in a public repository. Do not include passwords or sensitive information. Changes are committed to GitHub and may take time to appear on GitHub Pages.
